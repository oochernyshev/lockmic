What is LockMic?

A system-wide mic mute for macOS.

LockMic runs in the menu bar and mutes your microphone hardware (or all inputs) through Core Audio. Unlike Zoom or Meet mute—which only affect that app—LockMic blocks capture for everything on your Mac. Ideal for calls, streaming, and privacy when you need one reliable mute.

Features

Built for calls you can’t miss.

Everything you need to control the mic without hunting for the right mute button in the right app.

🎙

Mute all inputs

By default LockMic mutes every controllable input device — ideal when Zoom and Meet disagree about which mic is “the” mic.

⌘

Global hotkeys

Toggle with ⌘⇧M (and optional ⌘F5). Add mute-only, unmute-only, push-to-talk, push-to-mute, and push-to-flip. Conflict warnings included.

◈

On-screen HUD

Brief toast on mute/unmute. Optional floating indicator on each display — drag to move, click to toggle, right-click to hide.

☰

Menu bar control

Click the icon to toggle. Right-click for status, mute scope, floating HUD per display, and Preferences.

◎

Smart devices

Virtual Core Audio devices are listed but ignored for mute control. Re-applies mute when devices or the default input change.

🌐

23 languages

Follows your macOS language automatically — English, German, French, Spanish, Japanese, Chinese, Korean, and many more.

FAQ

Quick answers

What is LockMic?

LockMic is a free, open-source macOS menu bar app that mutes your microphone at the system level using Core Audio. It works in Zoom, Microsoft Teams, Google Meet, FaceTime, browsers, and every other app—not just inside one app’s mute button.

How is this different from Zoom’s mute button?

App mute only silences that app. LockMic mutes the input device in Core Audio, so every app sees a muted mic — including ones without a good mute control.

Does it work with virtual mics?

Virtual devices (Core Audio transport type Virtual) appear in the list but are ignored for mute control, so software mixers and virtual cables aren’t thrashing.

What data is sent?

In the app, if you agree: version and anonymous action events (toggle, mute/unmute, holds). No microphone audio, no personal data. Mute control stays off until you agree. This website uses the same Google Analytics property for anonymous page views (and optional download clicks) so we can improve the product and site.

Is it free?

Yes. LockMic is MIT-licensed open source from WIXEE.AI. Optional paid Pro modules may appear later; the core stays open.

How do I install LockMic?

Download the DMG from this site or GitHub Releases and drag LockMic to Applications, or use Homebrew (see Download above). Requires macOS 14+. Until notarized, run xattr -dr com.apple.quarantine /Applications/LockMic.app after install.
