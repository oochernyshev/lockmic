What is LockMic?

A system-wide mic mute for macOS.

LockMic runs in the menu bar and mutes your microphone hardware (or all inputs) through Core Audio. Unlike Zoom or Meet mute—which only affect that app—LockMic blocks capture for everything on your Mac. Ideal for calls, streaming, and privacy when you need one reliable mute.

Features

Built for calls you can’t miss.

Everything you need to control the mic without hunting for the right mute button in the right app.

Record locally New in 1.4

Optionally capture your default mic and what you hear. LockMic writes a dated mix on your Mac — nothing is uploaded, and mute still works while you record.

Mute all inputs

By default LockMic mutes every controllable input device — ideal when Zoom and Meet disagree about which mic is “the” mic.

Global hotkeys

Toggle with ⌘⇧M (and optional ⌘F5). Add mute-only, unmute-only, push-to-talk, push-to-mute, and push-to-flip. Conflict warnings included.

On-screen HUD

Brief toast on mute/unmute. Optional floating indicator on each display — drag to move, click to toggle, right-click to hide.

Menu bar control

Click the icon to toggle. Right-click for status, mute scope, floating HUD per display, and Preferences.

Stays muted

New mics and headsets you plug in later are muted too. If an app tries to unmute the input, LockMic re-applies mute so you stay covered system-wide.

23 languages

Follows your macOS language automatically — English, German, French, Spanish, Japanese, Chinese, Korean, and many more.

FAQ

Quick answers

What is LockMic?

LockMic is a free, open-source macOS menu bar app that mutes your microphone at the system level using Core Audio. It works in Zoom, Microsoft Teams, Google Meet, FaceTime, browsers, and every other app—not just inside one app’s mute button.

How is this different from Zoom’s mute button?

App mute only silences that app. LockMic mutes the input device in Core Audio, so every app sees a muted mic — including ones without a good mute control.

Does it work with virtual mics?

Virtual microphones show up in the list but LockMic doesn’t mute them, so virtual mixers and cables keep working as expected.

What data is sent?

In the app, if you agree: version and anonymous action events (toggle, mute/unmute, holds, recording start/stop). No microphone audio, no recording files, and no personal data. Mute control stays off until you agree. This website uses the same Google Analytics property for anonymous page views (and optional download clicks) so we can improve the product and site.

Can LockMic record audio?

Yes — optionally, from 1.4. Start Recording in the menu bar captures your default microphone and system playback, then writes a dated mix on your Mac (Movies/LockMic by default). Recordings stay on your disk. LockMic does not upload them. macOS asks for microphone and system audio access first.

Is it free?

Yes. LockMic is MIT-licensed open source from WIXEE.AI. Optional paid Pro modules may appear later; the core stays open.

How do I install LockMic?

Download the DMG and drag LockMic to Applications, or use the Homebrew commands in Download. Requires macOS 14+. If macOS blocks the app, run xattr -dr com.apple.quarantine /Applications/LockMic.app.

How do I update to the latest version?

Homebrew: run the same commands as install (see Download). DMG: download the latest DMG, replace the app in Applications, then open it.

I deleted LockMic.app. How do I install it again?

Run the Homebrew commands in Download again — reinstall puts the app back. To uninstall completely: brew uninstall --cask lockmic. DMG users can download the DMG and drag LockMic back to Applications.
