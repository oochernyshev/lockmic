# Security Policy

## Reporting a vulnerability

If you find a security vulnerability in LockMic, please report it privately by email to **info@wixee.ai** rather than opening a public issue.

Please include:

- A description of the issue and its potential impact
- Steps to reproduce, or a proof of concept
- The affected LockMic version and macOS version

We will acknowledge your report as soon as we can, keep you updated while we investigate, and credit you in the fix if you wish.

## Supported versions

Security fixes are released for the latest version of LockMic.
