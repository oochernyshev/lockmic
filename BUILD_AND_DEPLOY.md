# Build, deploy, and release

Local build and the public ship process. Day-to-day run commands also live in [README.md](./README.md). Website CI detail: [website/README.md](./website/README.md).

Builds are **ad-hoc signed, not Developer ID notarized**. First launch after download: right-click → Open, or `xattr -dr com.apple.quarantine /Applications/LockMic.app`.

## Prerequisites

- macOS 14 Sonoma or later
- Xcode 15+ (command-line tools on `PATH`)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) and [GitHub CLI](https://cli.github.com) for releases:

```bash
brew install xcodegen gh
gh auth login
```

## Local build and run

From the repo root:

```bash
./Scripts/start.sh            # build if missing, then restart
./Scripts/start.sh --build    # always rebuild, then restart
./Scripts/build_homebrew.sh   # Release .app only → build/LockMic.app
```

`build_homebrew.sh` runs `xcodegen generate`, builds **Release**, copies to `build/LockMic.app`, and ad-hoc signs. Do not hand-edit `LockMic.xcodeproj`; regenerate it.

Clean rebuild:

```bash
rm -rf build/
./Scripts/build_homebrew.sh
```

If Gatekeeper blocks the local app:

```bash
xattr -dr com.apple.quarantine build/LockMic.app
open build/LockMic.app
```

## Package zip and DMG

Requires `build/LockMic.app` from the step above. Version in the filenames comes from the app Info.plist.

```bash
./Scripts/package_dmg.sh
# → build/dist/LockMic-X.Y.Z.zip
# → build/dist/LockMic-X.Y.Z.dmg
# → matching .sha256 files
```

The zip is the Homebrew cask asset. The DMG is the website / GitHub download. The script prints SHA-256; copy the **zip** hash into the cask.

## Publish a release

Working tree must be **clean** and you must be on **main**. The script bumps every version file, Release-builds, packages, stamps the cask SHA-256, commits, tags, pushes `main` **and** the tag, then creates the GitHub release immediately so cask/website URLs do not 404.

```bash
# Product changes already committed.
./Scripts/release.sh 1.4.36 -m "one-line summary of the ship"

# Custom GitHub body (otherwise “What’s new” + the -m line):
./Scripts/release.sh 1.4.36 -m "one-line summary" --notes-file notes.md

# Inspect the commit/tag locally first:
./Scripts/release.sh 1.4.36 -m "one-line summary" --no-push
```

`-m` is the git commit (`Release X.Y.Z: …`) and the ARCHITECTURE phase-map row. `--notes` / `--notes-file` should match recent releases: short “What’s new” bullets, no fluff.

It refuses to run if `Info.plist`, `project.yml` (both `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` pairs), and `Casks/lockmic.rb` do not already agree. Build number is last + 1. `homebrew/Casks/lockmic.rb` is a symlink; only `Casks/lockmic.rb` is edited.

### What the script touches

| File | What |
|------|------|
| `Resources/Info.plist` | `CFBundleShortVersionString`, `CFBundleVersion` |
| `project.yml` | both `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION` pairs |
| `LockMic.xcodeproj/project.pbxproj` | regenerated by XcodeGen during the Release build |
| `README.md` | header version; dist filename example |
| `ARCHITECTURE.md` | header version; new phase-map row |
| `website/public/index.html` | every current `X.Y.Z` (title, JSON-LD, href, `?v=`) |
| `website/public/llms.txt` | current version and DMG URL |
| `Casks/lockmic.rb` | `version` and zip `sha256` |

Manual equivalent (only if you cannot run the script): bump the table above, `./Scripts/build_homebrew.sh && ./Scripts/package_dmg.sh`, paste the zip SHA-256 into the cask, commit, `git tag vX.Y.Z`, `git push origin main && git push origin vX.Y.Z`, then `gh release create` with dmg, zip, and both `.sha256` files.

### 4. Website

Push to `main` already triggers **Cloud Build** → Firebase Hosting (`cloudbuild.yaml`). `website/public/main.js` also rewrites the DMG button from `GET /repos/oochernyshev/lockmic/releases/latest`, but JSON-LD and the visible “Get LockMic X.Y.Z” heading stay whatever you committed in `index.html`.

Do **not** `cd website/public && firebase deploy` (`firebase.json` is at the repo root). Manual deploy only if CI did not run:

```bash
# repo root
gcloud config set project lockmic-11c1a
gcloud builds submit --config cloudbuild.yaml .
```

Local preview: `cd website/public && python3 -m http.server 8080`

### 5. Check the ship

- Release page: https://github.com/oochernyshev/lockmic/releases/tag/vX.Y.Z (DMG + zip + both checksums)
- https://lockmic.com — heading and download match `X.Y.Z`
- Homebrew (tap already installed):

```bash
brew update
brew reinstall --cask --yes lockmic || brew install --cask lockmic
xattr -dr com.apple.quarantine /Applications/LockMic.app
open /Applications/LockMic.app
```

First-time tap:

```bash
brew tap oochernyshev/lockmic https://github.com/oochernyshev/lockmic
brew trust --cask oochernyshev/lockmic/lockmic
```

Homebrew 6 `upgrade --cask` / `install --force` can no-op if it thinks the cask is current; `reinstall --cask --yes` is the command that actually replaces the app.

## Troubleshooting

| Problem | What to do |
|---------|------------|
| `xcodegen: command not found` | `brew install xcodegen` |
| Script not executable | `chmod +x Scripts/*.sh` |
| Code-sign noise in `xcodebuild` | Scripts force ad-hoc (`CODE_SIGN_IDENTITY=-`). Official notarization is not wired yet. |
| `gh` not authenticated | `gh auth login` |
| App won’t open after download | `xattr -dr com.apple.quarantine` on the `.app` |
| Cloud Build “No buildpack groups passed detection” | Trigger must use `cloudbuild.yaml`, never Buildpacks / Autodetect |

## If you have to roll back

```bash
gh release delete vX.Y.Z --yes
git push origin :refs/tags/vX.Y.Z
git revert HEAD
git push origin main
```

Then ship a new patch version; do not reuse `vX.Y.Z` if anyone already downloaded it.
